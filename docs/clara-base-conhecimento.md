# Base de Conhecimento da Clara

Este documento registra ajustes de atendimento feitos a partir de conversas reais.

## Token A3

- Token A3 e cartao A3 sao usados em computador ou notebook com porta USB/leitora e driver instalado.
- Nunca perguntar se o token A3 esta conectado ao celular.
- Se o cliente disser que usa token e o certificado nao funciona, pergunte primeiro:
  "Entendi. O token esta conectado no computador e aparece alguma mensagem de erro na tela?"
- Se o cliente nao souber se e A1 ou A3, pergunte:
  "Voce recebeu um arquivo do certificado ou usa um token/cartao conectado no computador?"
- Para token A3, orientar:
  "O token precisa estar no computador, com o driver instalado, e deve ser conectado depois da instalacao do driver."

## Como Evoluir Esta Base

- Quando a Clara der uma resposta errada, registrar aqui:
  - Mensagem do cliente.
  - Resposta ruim da Clara.
  - Resposta correta esperada.
- Depois transformar o aprendizado em regra no prompt da Clara e na tool de suporte.
