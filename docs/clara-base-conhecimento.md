# Base de Conhecimento da Clara

Este documento registra ajustes de atendimento feitos a partir de conversas reais.

## Token A3

- Token A3 e cartao A3 sao usados em computador ou notebook com porta USB/leitora e driver instalado.
- Nunca perguntar se o token A3 esta conectado ao celular.
- Se o cliente disser que usa token e o certificado nao funciona, pergunte primeiro:
  "Entendi. O token esta conectado no computador e aparece alguma mensagem de erro na tela?"
- Se o cliente nao souber se e A1 ou A3, pergunte:
  "Voce recebeu um arquivo do certificado ou usa um token/cartao conectado no computador?"
- Para token A3, orientar:
  "O token precisa estar no computador, com o driver instalado, e deve ser conectado depois da instalacao do driver."

Links Safeweb:
- Instalacao e emissao: https://www.safeweb.com.br/suporte/instalacao
- A3 token ou cartao: https://www.safeweb.com.br/suporte/instalacao/tokenoucartao
- Central de downloads: https://www.safeweb.com.br/suporte/centraldedownloads
- Drivers de token: https://www.safeweb.com.br/centraldedownloads/token

## Tipos de Certificado

- e-CPF: certificado para pessoa fisica.
- e-CNPJ: certificado para pessoa juridica/empresa.
- NF-e/PJ: certificado voltado a rotinas fiscais/emissao de nota quando aplicavel ao produto comprado.
- A1: certificado em arquivo/importacao no computador. Nao usa token fisico.
- A3 token/cartao: certificado em midia fisica, usado em computador/notebook com USB ou leitora.
- SafeID/nuvem: certificado em nuvem/app. Nao e token USB e nao deve receber orientacao de driver SafeSign como se fosse midia fisica.

## A1 - Arquivo

- A1 e certificado em arquivo, normalmente instalado/importado no computador.
- Nao tratar A1 como token fisico.
- Se o cliente disser que o A1 nao instala, pergunte:
  "Voce ja abriu o Assistente de Certificado Digital da Safeweb e em qual etapa apareceu o erro?"
- Para instalacao A1, orientar o uso do Assistente de Certificado Digital Safeweb:
  https://instalacaocertificado-acsafeweb.safewebpss.com.br/

## SafeID / Nuvem

- SafeID/nuvem nao e token USB.
- Referencia SafeID: https://hotsite-safeweb.safewebpss.com.br/produtos/safeid
- Nao orientar instalacao de driver SafeSign quando o cliente estiver falando de certificado em nuvem/SafeID.
- Se o cliente citar SafeID, perguntar:
  "Voce esta tentando acessar pelo app/ambiente SafeID ou em algum sistema especifico?"

## Videoconferencia

- Nunca prometer videoconferencia sem triagem.
- Primeiro perguntar se e primeiro certificado ou renovacao.
- Se for primeiro certificado, verificar CNH valida/digital ou necessidade de consulta de biometria.
- Se nao houver CNH valida/digital nem biometria confirmada, orientar atendimento presencial.

## e-CAC

- e-CAC depende de certificado valido e reconhecido no navegador/sistema.
- Primeira pergunta:
  "O certificado aparece para selecionar no navegador quando voce entra no e-CAC?"
- Se nao aparece, diferenciar A1 de A3 antes de orientar.

## Como Evoluir Esta Base

- Quando a Clara der uma resposta errada, registrar aqui:
  - Mensagem do cliente.
  - Resposta ruim da Clara.
  - Resposta correta esperada.
- Depois transformar o aprendizado em regra no prompt da Clara e na tool de suporte.
